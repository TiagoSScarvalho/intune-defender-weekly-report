# Security

Do not upload tenant reports, device identifiers, tokens, private keys or raw authentication errors to public issues. Reproduce problems using redacted/synthetic data and include the script version and safe HTTP status/category only.

This collector is read-only and makes no remediation decisions. Its permission scope may be wider than its configured device list. Protect the run identity, certificate private key, report storage and retention. Review dependencies and code before execution.

For sensitive disclosures, use a private contact channel listed on the author's website. Do not post sensitive details while requesting a private channel in an issue.
